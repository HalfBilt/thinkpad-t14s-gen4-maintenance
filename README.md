`%APPDATA%\_repo_backup_20261020` 是旧备份，确认无误后可删。

### 三个"别踩"的坑

1. **`0x40` 要 20~25 秒才升到位。** `16-风扇档位标定.py` 的 `SETTLE_S` 已从 12 改成 25。
   等 12 秒会测出 4160 的**假值**，并据此得出"0x40 不是满速"的错误结论（已撤回）。
   真值：`0x40` = 4807（日志实测 4608~4901）。
2. **中高档位转速受温度影响**（同一天两次标定差 300~500 转：`0x07` 4388 vs 3858）。
   **曲线只看档位顺序**（1<2<…<7<`0x40`），别拿转速当判据。
3. **`2-check` 的"版本一致性"** 现在比的是「git 是否干净」+「文件 mtime vs 最后一次服务就绪」，
   不再是 SHA256 —— 合并后比 SHA256 等于比自己。

### 当前未解决

- **凌晨意外断电**（10-18 16:43、10-20 03:20，都是 `Event 6008`）。
  取证：AC 插着、电池 87%、**低负载**、无 `41`/`88`/`1074`/`1001`、日志瞬间中断。
  → 判断为**硬件供电中断**（主板 VRM 低负载瞬态 / EC 看门狗）。
  **已关风扇减少 EC 写入做对照实验**，观察 2~3 天：如果不再断，说明与 EC 访问有关。
- **风扇 2↔6 抖动**（10.5 次/小时，`06` §3.1）—— 关风扇后消失，但重开仍会。
  根因是物理极限环（2 档 2610 RPM 在 50~56°C 不能稳态），回差/驻留只能拉长周期。
